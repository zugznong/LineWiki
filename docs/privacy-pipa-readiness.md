# 개인정보 / PIPA 대응 준비 문서 (Privacy & PIPA Readiness)

> 이 문서는 LineWiki가 **개인정보 보호법(PIPA, 개인정보 보호법)** 적용 대상이 되는
> 기능을 추가하기 *전에* 준비해야 할 사항을 정리한 개발자용 체크리스트입니다.
> 법률 자문 문서가 아니며, "완전한 PIPA 준수"를 보증하지 않습니다.

## 1. 현재 상태 (오픈베타 0)

LineWiki 오픈베타 0은 **클라이언트 전용 정적 애플리케이션**입니다.

| 항목 | 현재 상태 |
| --- | --- |
| 계정/로그인 | 없음 |
| 서버 측 사용자 데이터 저장 | 없음 |
| 서버 분석 요청 | 비활성화 (`DisabledServerAnalysisAdapter`) |
| 개인 노트 / 토론 / 통계 | 비활성화 자리표시자 (`Disabled*`) |
| 브라우저 저장소 | 보드 설정 → `localStorage`, 수순 기록 → `sessionStorage` |
| 외부 네트워크 전송 | 정적 자산 로드 외 없음 |
| 로그에 남는 FEN | 비식별 토큰으로 치환 (`redactFen`) |

이 단계에서는 개인을 식별할 수 있는 정보를 수집·저장·전송하지 않으므로 PIPA상 "개인정보 처리"
범위에 직접 해당하지 않습니다. 다만 아래 기능이 도입되면 즉시 적용 대상이 됩니다.

## 2. 신규 기능 도입 시 PIPA 체크리스트

아래 기능 중 하나라도 도입하기 전에, 각 항목을 검토하고 사용자용 개인정보 처리방침과
내부 처리 절차를 갱신해야 합니다.

- [ ] **수집 목적**: 어떤 데이터를 *왜* 수집하는지 항목별로 명시했는가?
- [ ] **데이터 카테고리**: 식별정보 / 민감정보 / 행태정보 등 유형을 분류했는가?
- [ ] **보관 기간**: 항목별 보관 기간과 파기 시점/방법을 정의했는가?
- [ ] **동의 근거**: 수집·이용에 대한 동의를 어떻게 받는가? (필수/선택 구분)
- [ ] **삭제 요청 경로**: 이용자가 자신의 데이터 삭제를 요청할 수 있는 경로가 있는가?
- [ ] **열람/내보내기 요청 경로**: 이용자가 자신의 데이터를 열람·다운로드할 수 있는가?
- [ ] **제3자 제공 고지**: 외부로 데이터를 전송한다면 수신자·목적·항목을 고지했는가?
- [ ] **처리·수탁 업체 목록**: 처리위탁/재위탁 업체(예: 호스팅, 분석)를 명시했는가?
- [ ] **신고/악용 대응 절차**: 침해사고·악용 신고 및 대응 워크플로가 있는가?
- [ ] **아동·미성년자 고려**: 만 14세 미만 등 미성년 이용자 처리 기준이 필요한가?

## 3. 기능별 위험도 메모

| 도입 기능 | PIPA 관련 위험 | 우선 검토 사항 |
| --- | --- | --- |
| 로그인 / 사용자 ID | 식별정보 수집 시작 | 동의, 보관/파기, 최소수집 |
| 개인 노트 서버 저장 | 사용자 연구 데이터 = 행태정보 | 암호화, 접근통제, 삭제권 |
| 토론 / 커뮤니티 | 작성자 식별·게시물 | 신고/차단, 작성자 표기 범위 |
| 외부 통계 API | 제3자 데이터 전송 | 제3자 제공 고지, FEN 전송 범위 |
| 원격 Stockfish 분석 | FEN(연구 국면) 서버 전송 | 전송 최소화, 로그 보존 정책 |
| Analytics / 텔레메트리 | 행태정보·식별자 수집 | 동의 기반, 익명화/가명화 |

## 4. 기술적 메모

- FEN은 그 자체로 사용자의 연구 관심사를 드러낼 수 있으며, 계정과 연결되면 개인정보가 될 수
  있습니다. 로그·텔레메트리에서는 `src/lib/utils/safeLog.ts`의 `redactFen()`을 사용해
  원본 FEN을 비식별 토큰으로 치환합니다.
- 서버 기능 도입 시 전송 데이터를 최소화하고(필요한 FEN 필드만), 전송 구간 암호화(HTTPS)와
  서버 로그 보존 정책을 함께 정의합니다.
- 사용자용 안내 페이지는 `/privacy` (`src/routes/privacy/+page.svelte`)에 있으며,
  데이터 처리 방식이 바뀌면 함께 갱신합니다.
