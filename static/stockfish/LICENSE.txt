Stockfish Chess Engine WASM/JS Integration

This directory supports client-side chess analysis within the LineWiki platform.

[IMPORTANT NOTE FOR OPEN BETA 0]:
The native heavyweight "stockfish.wasm" binary is completely excluded from the Open Beta 0 distribution bundle to minimize download size and ensure offline client-first simplicity. This folder contains only a stockfish-compatible mock / fallback JS script ("stockfish.js") and a placeholder text. For true local grandmaster analysis, the user can manually drop a compiled GPLv3 stockfish.wasm into this folder.

1. Fallback / Mock Adapter Build (ACTIVE in Open Beta 0):
   Utilizes compatible mock adapters and a lightweight local Web Worker heuristic evaluator written in TypeScript/JS, compiled directly into the application wrapper.

2. Standard Stockfish Build (INACTIVE/UPGRADABLE):
   Supports replacing the placeholder mock scripts with real WebAssembly releases of the official Stockfish Chess Engine, utilizing identical UCI protocol interfaces.
